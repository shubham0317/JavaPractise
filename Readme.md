## ▶️ How to Run the Programs

You can run these Java programs using Eclipse IDE or any Java-compatible development environment.

**Using the terminal:**

1. Clone the repository:

   ```bash
   git clone https://github.com/shubham0317/JavaPractise.git
   ```

2. Navigate to the project directory:

   ```bash
   cd JavaPractise
   ```

3. Compile a Java file:

   ```bash
   javac HelloWorld.java
   ```

4. Run the compiled class:

   ```bash
   java HelloWorld
   ```

**Prerequisite:** Install a compatible JDK and ensure `java` and `javac` are available in your terminal. If a program uses a package declaration, compile and run it from the appropriate directory.
